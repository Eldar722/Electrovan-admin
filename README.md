# ElectroVan Admin

Админ-панель для демо-версии ElectroVan. Она управляет каталогом электровэнов, контактами сайта и входящими заявками клиентов.

## Что умеет демо

- Вход администратора через Supabase Auth.
- Просмотр, добавление, редактирование и удаление авто.
- Загрузка изображения авто в Supabase Storage.
- Управление публикацией авто на сайте через флаг `Активно на сайте`.
- Выбор популярных моделей для главной страницы.
- Обновление телефона, WhatsApp, email и Telegram на сайте.
- Просмотр заявок клиентов.
- Смена и сохранение статуса заявки.
- Поиск заявок по имени, телефону, дате и заметке.
- Карточка заявки с быстрым звонком, WhatsApp и заметкой менеджера.

## Локальный запуск

```bash
npm install
npm run dev
```

По умолчанию Vite откроет локальный адрес в терминале, обычно `http://localhost:5173`.

## Переменные окружения

Создайте `.env` на основе `.env.example`:

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

Эти же значения должны использоваться в публичном приложении `electrovan-app`.

## Supabase setup

Перед демо примените SQL-миграции из папки `../supabase/migrations` в Supabase SQL Editor по порядку:

1. `001_rls_policies.sql`
2. `002_add_image_url.sql`
3. `003_user_roles_and_rls.sql`
4. `004_site_settings_and_lead_status.sql`
5. `005_harden_lead_status_persistence.sql`
6. `006_demo_admin_fields.sql`

После миграции `003` нужно добавить первого администратора:

```sql
INSERT INTO user_roles (user_id, role)
VALUES ('<supabase-auth-user-uuid>', 'admin');
```

UUID берётся в Supabase Dashboard: Authentication -> Users.

## Проверка перед показом

```bash
npm run lint
npm run build
```

Обе команды должны завершаться без ошибок.

## Рекомендуемые демо-данные

- 5-8 авто с реальными названиями, ценами, характеристиками и изображениями.
- 2-3 авто отмечены как популярные.
- 1 авто скрыто с сайта, чтобы показать контроль публикации.
- 10-15 заявок в разных статусах.
- У нескольких заявок заполнены заметки менеджера.

## Сценарий показа

1. Войти в админку.
2. Показать каталог и редактирование карточки авто.
3. Скрыть или опубликовать авто через `Активно на сайте`.
4. Показать, что контакты сайта редактируются из админки.
5. Открыть заявки, найти клиента через поиск.
6. Открыть карточку заявки, изменить статус, добавить заметку.
7. Обновить страницу и показать, что статус и заметка сохранились.
